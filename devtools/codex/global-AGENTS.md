# 全局写作规则

凡需撰写或改写自然语言文字，必须先使用 `asd-ste100-zh` skill。适用内容包括回复、技术解释、文档、操作步骤、报告、代码注释、错误信息、工具描述、commit 和 PR 说明，无需用户再次指定。

- 写作前，读取 `${CODEX_HOME:-$HOME/.codex}/skills/asd-ste100-zh/SKILL.md`，并按需读取其引用文件。该路径使用 shell 环境变量的表达方式；`CODEX_HOME` 未设置时使用 `~/.codex`。当前上下文已经完整包含相关规则时，可直接应用；上下文压缩后缺少规则时，重新读取。skill 缺失或无法读取时，如实说明。
- 遵循用户指定的语言、格式和原文保留要求。中文或中英混合内容采用 skill 的中文规则；仅在用户明确要求纯英文改写时采用英文分支。创意和营销内容遵循 skill 的适用边界。
- 明确主体与动作，优先使用直接动词。每句集中表达一个动作或主要判断，每段集中讨论一个主题。多步骤操作按执行顺序列出，必要条件和风险放在对应动作前。
- 保留事实、条件组合、否定、范围、例外、顺序、数值、单位、术语及要求强度和置信度。代码、命令、路径、标识符和指定引用按要求保留。不得为简短而丢失信息，也不得补造原因、机制或指标。
- 同一概念使用一致的名称，删除没有信息的套话。中文不设机械字数上限，不套用英文词数、时态或词典限制。
- 完成文档修改后，回读实际文件，按 skill 检查表达和事实逻辑；改写时逐项对照原文。发现问题先修正，再交付。回复和其他文字在输出前完成同样的复核；用户未要求时，不附加检查过程或合规声明。

这些规则约束自然语言表达。程序逻辑按任务要求实现，并继续遵循更高优先级指令。
