# Phase 0：工程骨架

> 本文档是阶段开发提纲，具体接口、数据模型、消息格式和部署参数将在本阶段进入详细设计时补充。

## 版本规划

- 版本线：`0.1.x`；阶段基线：`0.1.0`。
- 执行批次从 `0.1.1` 起编号，具体目标版本和开发分支由 Phase 0 总实施方案统一分配。

## 阶段目标

建立可长期演进的项目结构、本地开发环境以及前后端最小可运行链路。

本阶段完成后，应形成可独立运行和验证的结果，并能够直接支撑 Phase 1。

## 开发范围

- 顶层工程目录。
- 最小 Vue 3 前端。
- 最小 Gin Backend。
- MySQL、Redis、RabbitMQ 本地开发环境。
- 统一配置入口与开发启动方式。

## 核心任务

- 建立前端、后端及后续自研组件的目录骨架。
- 提供 Backend 健康检查能力。
- 建立前端到 Backend 的最小访问链路。
- 通过 Docker Compose 准备本地基础设施。
- 整理统一配置与一键启动入口。

## 前置依赖

- 无前置开发阶段。
- 本地具备 Go、Node.js、Docker 与 Docker Compose 开发条件。

## 阶段产物

- 可访问的最小前端。
- 可启动的 Gin Backend。
- 可连接的 MySQL、Redis、RabbitMQ。
- 明确的本地开发启动说明。

## 验收标准

- 前端与 Backend 均可启动和访问。
- Backend 健康检查返回正常。
- Backend 能连接三项基础设施。
- 开发者可通过一条明确命令启动开发环境。

## 本阶段不做

- 业务功能。
- Kafka、VictoriaMetrics、Elasticsearch。
- Monitor、Marshaller、Exporter。
- Kubernetes 部署。

## 后续待细化事项

- 具体代码目录与模块边界。
- 对外及内部接口定义。
- 数据结构、消息结构或存储结构。
- 配置项、运行参数与异常处理细节。
- 本阶段任务拆分、测试用例与实施顺序。
