产品完成版本只读取根目录 [VERSION](../VERSION)，文档整理不改变版本或实施状态。

## 维护约定

- `imple/Phase-XX` 与 `logs/Phase-XX` 保持对应的目录和 Markdown 文件名；额外诊断记录按实际性质保留。
- 实施日志中的原始证据、候选标识、回执和归档保持原样，不因分类整理而重写。
- 技术文档中的 Phase 或版本标识限定其合同范围，不自动代表当前全部能力。
- 未来设计不分配实施 Phase、版本或分支；实施前以总纲和正式实施方案确定范围。
- 新增普通文档按职责归类，避免重新散落在本目录根部；移动文件时同步检查本地链接和路径引用。

少量旧 `docs` 路径保留导航页供模块说明与历史工具引用；技术正文只在本目录维护。
