## 维护约定

- 两份架构设计与落地大纲冻结为 2026-10-06 基线，原文不再更新。后续链接、决策及实施映射由设计索引维护；改变目标须经用户批准建立新基线并保留旧文件。
- 当前能力事实与证据边界集中维护在能力状态；完成产品版本只读取根 VERSION。
- 批次、目标版本、分支和门禁由实施合同负责；索引、提纲与设计入口引用正文，不复制状态或验收数值。
- 收口时登记能力状态、合同完成标记、实际日志和证据；导航链接仍有效时无需同步修改。
- 已完成方案、日志、评审和原始证据保留原路径与历史上下文；规则细节见 [AGENTS.md](../AGENTS.md)。
