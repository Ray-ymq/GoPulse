## 维护约定

- `docs/` 维护两篇目标设计、图解入口和读者导航；`dev/` 维护实施、契约、操作、验收与历史材料。
- `imple/Phase-XX` 与 `logs/Phase-XX` 保持对应的目录和 Markdown 文件名；额外诊断记录按实际性质保留。
- 已完成计划、日志、评审和原始证据不搬家；导航区分当前工作与历史记录。
- 技术文档中的 Phase 或版本标识限定其合同范围，不自动代表当前全部能力。
- 未来设计不预留 Phase、版本或分支；批次顺序与执行授权由正式总实施方案确定。
- 引用现存正文路径，不再依赖已删除的旧 `docs` 导航页。
