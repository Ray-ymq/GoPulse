# 管理中心展示（1.14.1）

通过统一登录进入 `/admin/`。只有服务端确认的超级管理员才会挂载管理页面；普通用户返回社交。管理 API 与双 Frontend 继续使用同源 edge，不提供浏览器直连内部服务的入口。

## 导航与屏幕尺寸

桌面使用左侧分组导航和顶部工具栏，提供管理大屏、Metrics、Logs、Events、告警、Exporter、用户角色、审计、当前账号、返回社交和退出登录。窄屏通过“管理导航”展开或收起导航；选择页面后自动收起。键盘首个链接“跳至主要内容”可跳过导航，当前路由有文本高亮和 `aria-current`。

## 数据口径

- **管理大屏**：摘要及六个分区均来自 overview DTO。健康组件分母是实际返回的组件数量，不是静态 `6/6`；不完整分区的摘要显示“未知”。组件是 GoPulse 六个业务进程，不冒充数据库基础设施。卡片保留状态、原因码和“采样详情”，可以核对时间和其他安全字段。
- **指标快照与趋势**：overview 不包含历史序列，因此大屏不绘制参考图的静态趋势。Metrics 只查询已有指标目录与时间范围，按真实采样时间和值绘制 SVG，纵轴按每条时序的最小/最大值缩放；常量序列水平显示，单点不补造趋势。最近采样表保留精确数值。不同纵轴的时序不应用视觉高度直接比较。
- **日志**：保留服务、模块、级别、固定消息、Request ID、Event ID 和错误码精确过滤。“已加载日志摘要”只统计当前已加载的记录（含加载更多），不是整个时间窗口总量。安全 metadata 自动换行，不展示原始日志文档。
- **Exporter**：六插件目录、目标配置与运行状态并列展示；表单仅由现有服务器 schema 生成。密码不回填，提交后清空；连接测试、配置替换、安装更新和启动停止沿用原安全约束。进程 running 不等同于目标健康；请同时查看采样时间和安全错误。

空结果、未知、部分不可用和查询失败不是相同状态；页面失败时按提示重试，不把 unknown 当作 0 或恢复。没有实时数据支撑的全平台健康徽章、环形比例、延迟条和内部示例地址不予展示。

## 本批验收入口

`python3 scripts/ci/verify_admin_visual.py` 创建独立、有归属标签的真实 Linux amd64 Compose 验收环境，执行现有管理、dashboard、真实依赖停机 partial 和专用响应式浏览器用例。截图保存到输出 evidence 目录的 `screenshots/`；包含 1440×1000、820×1000、390×844 四页截图。普通页面状态不使用 API mock。结束时清理本次容器、网络、卷、临时凭据和候选镜像，不删除已有资源。

这个入口只用于本批展示验收，不替代 Phase 17 后续运行时/持久状态/全产品验收。
