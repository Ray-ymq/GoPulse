# GoPulse 技术栈

GoPulse 用 Go 写业务服务与自研观测组件，用两个 Vue 应用提供用户端和管理端，数据分别落在关系库、缓存、消息队列、搜索集群和时序库中。下表记录当前工作树实际使用的选型，版本以各模块的 `go.mod`、两个 `package.json`、`deploy/compose.yaml` 与 `deploy/docker` 下的镜像定义为准。

## 语言与运行时

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Go | 1.26 | 十五个业务、观测与工具模块 |
| TypeScript | 6.0.3 | 两个前端应用 |
| Node.js | 24.20.0 | 前端构建与开发服务器运行时 |
| npm | 11.19.0 | 前端依赖管理 |
| Python | 3.12 以上 | 工程脚本与 CI 治理脚本 |
| GNU Make | 不限 | 根目录按模块分派命令 |

## 业务后端

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Gin | 1.12 | HTTP 接口 |
| database/sql 与 go-sql-driver/mysql | 1.10 | MySQL 访问 |
| golang-migrate | v4.19 | 数据库迁移 |
| go-redis | v9.22 | Redis 客户端 |
| amqp091-go | 1.14 | RabbitMQ 异步消息 |
| log/slog | 标准库 | 结构化日志 |
| bcrypt（x/crypto） | 0.48 | 口令哈希 |
| HMAC-SHA256 | 标准库 | 管理端与查询接口令牌签名 |
| OpenTelemetry SDK | 1.37 | 链路追踪，经 OTLP/gRPC 导出 |
| 自研 Elasticsearch 客户端 | 标准库 net/http | 搜索索引读写 |

同一份代码编译出六个程序：`server`、`business-worker`、`search-indexer`、`search-reindex`、`migrate`、`admin-role`；启动时按 `BACKEND_SERVICE_ROLE` 选择 combined、business 或 platform 角色。

## 观测链路

| 组件 | 关键依赖 | 职责 |
| --- | --- | --- |
| router | 标准库 net/http、franz-go 1.21 | 接收内部消息并校验令牌与幂等键，写入 Kafka |
| marshaller | franz-go 1.21 | 消费 Kafka，指标导入 VictoriaMetrics，日志与事件写入 Elasticsearch，执行保留期策略 |
| monitor | prometheus/client_model、prometheus/common | 周期抓取 exporter 指标，以子进程管理 exporter 插件 |
| componentmetrics | 标准库 | 被 backend、router、marshaller、monitor 共用的组件运行与指标输出 |
| exporters | franz-go、go-redis、prometheus 客户端库 | 六个独立程序，采集 Redis、MySQL、RabbitMQ、Kafka、Elasticsearch、VictoriaMetrics |

## 协议与接口

| 场景 | 协议 |
| --- | --- |
| 业务接口与内部调用 | HTTP/1.1 加 JSON |
| 指标暴露与导入 | Prometheus 文本格式 |
| 链路追踪导出 | OTLP/gRPC |
| 业务异步消息 | AMQP 0-9-1 |
| 遥测传输 | Kafka 协议 |
| 搜索与日志读写 | Elasticsearch REST 接口 |
| 鉴权与幂等 | Bearer token、HMAC-SHA256 签名、幂等键 |

## 构建与交付

| 类别 | 技术 |
| --- | --- |
| 容器镜像 | Docker 多阶段构建，基础镜像按 digest 固定 |
| 编排 | Docker Compose，业务服务、router、marshaller 与后台任务多副本，网络分为 edge、business、observability |
| 命令行工具 | lifecycle 模块的 gopulse（安装、启停、状态、日志、校验、备份、恢复）与 gopulse-package（构建、校验、发布） |
| 发布产物 | 不可变 Bundle，含 SHA256 与 JSON Schema 校验 |
| 插件交付 | exporter 归档，插件合同版本 2 |
| 静态检查 | golangci-lint 2.14.0，启用 errcheck、staticcheck、unused |
| CI | GitHub Actions：quality-gates（模块矩阵与集成、端到端、Compose 验收）、auto-pr-merge、release-candidate、cache-warm |
| 本机开发 | devtools 的原生 Go 助手，工具链版本固定于 `devtools/toolchains.json` 并按 SHA256 校验 |
| 浏览器验收 | Playwright chromium；容器验收使用官方 playwright 镜像 |
| 容量测试 | loadtest 模块的 Go 程序，按 JSON 配方与 Schema 驱动 |
