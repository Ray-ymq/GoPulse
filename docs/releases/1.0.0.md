# GoPulse 1.0.0

版本日期：2026-09-03

## 里程碑

`1.0.0` 是 GoPulse Milestone 1 的业务系统 MVP 发布版本，汇总 Phase 0 至 Phase 3 已完成并通过验收的能力。本次 release-only 变更不增加产品功能，只同步版本元数据、里程碑状态和发布说明。

## 主要能力

- 可复现的 Go Backend、Vue Frontend 与 Docker Compose 本地开发环境，以及受资源归属保护的 Bash 生命周期和验收入口。
- 用户注册、登录与认证恢复，以及帖子发布、列表、详情、评论、点赞和取消点赞的完整业务闭环。
- Redis 帖子详情缓存与安全降级；Redis 故障不会改变 MySQL 业务事实。
- 基于事务 Outbox、RabbitMQ、独立 Business Worker 和幂等持久化的评论与首次点赞通知闭环。
- 通知 API、未读状态和受认证保护的 Frontend 通知页面。
- 以 MySQL 为最终事实源、Elasticsearch 为可删除和可重建投影的帖子全文搜索。
- `post.created` 可靠事件、独立 Search Indexer、增量收敛、全量重建和原子别名切换。
- 使用 Elasticsearch PIT、完整排序边界和 HMAC 签名 cursor 的稳定搜索分页，以及受控的 Frontend 失败重试和快照失效恢复。

## 验收基线

Phase 0 至 Phase 3 的实施记录保存了实际执行的 Backend、Frontend、治理、Compose、真实 MySQL/Redis/RabbitMQ/Elasticsearch 集成和浏览器业务闭环结果。Phase-03-04 的远程 push 质量门禁及 PR #51 合入关闭了 Milestone 1 发布前的实现 Review 整改。

本 release-only 分支仍须通过仓库配置的 Branch governance、Backend、Frontend、Scripts and Compose 与 Integration push 门禁。只有该变更合入 `main` 后，主分支根 `VERSION=1.0.0` 才代表正式发布完成。

## 已知边界

- 当前主要面向 WSL2 Linux filesystem 中的本地开发和验收；原生 Windows PowerShell 脚本冻结在 `0.2.1` 能力基线。
- Elasticsearch 是搜索投影而不是业务事实源；产品尚未提供帖子编辑或删除能力。
- 搜索 PIT 分页窗口为两分钟；快照过期后客户端需要从第一页重新搜索。
- 生产级高可用、容量规划、统一可观测能力和 Kubernetes 部署属于后续 Phase。
