| 设计 | 负责范围 |
| --- | --- |
| [高并发架构设计](<GoPulse 高并发架构设计.md>) | 业务模块、事实源、一致性、异步执行、容量与故障边界 |
| [可观测架构设计](<GoPulse 可观测架构设计.md>) | 观测数据、控制与查询、诊断实验，以及两篇共用的身份和环境资源契约 |
| [目标架构图解](../dev/design/diagrams/target-architecture/README.md) | 整体、业务、可观测三张目标图；以两篇设计正文为准 |
| [目标架构落地大纲](../dev/design/GoPulse-目标架构落地大纲.md) | 固定目标分解、设计产物、迁移依赖和系统成立条件 |
| [设计索引](../dev/design/README.md) | 生效基线、后续详细设计链接、决策和正式实施映射的维护入口 |

三份冻结原文不随实施更新。目标调整须核对两篇设计及大纲，经用户批准建立新基线，旧文件保留；流程见设计索引。新基线不自动改写已分配批次的版本、分支、验收合同或实际停点。
