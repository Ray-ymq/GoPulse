# GoPulse 压测指标汇总

| 组件 | 指标 |
| --- | --- |
| 前端页面 | LCP、INP、CLS、JS/CSS 传输字节、每页 API 请求数 |
| Nginx | 请求 QPS、P95、5xx 数、499/502/504 数、TLS 握手耗时、活跃连接数、静态资源请求数、CPU、内存 |
| API | 每路由 QPS、成功 QPS、P50/P95/P99、错误率、429 数、503 数（按 `error_code`）、5xx 数、超时数、在途请求数、并发拒绝数、登录/注册 P95 |
| MySQL | QPS（按语句类型）、SQL P95、慢查询数、扫描行数、全表扫描次数、临时表数、连接数、`Threads_running`、连接池等待、锁等待时间、死锁数、buffer pool 命中率、磁盘 IOPS、磁盘延迟 |
| Redis | 命令 QPS、命令 P95、命中率、内存使用、碎片率、`evicted_keys`、`expired_keys`、连接数、连接池等待、阻塞客户端数、AOF 延迟、限流脚本 P95 |
| RabbitMQ | `messages_ready`、`messages_unacknowledged`、最老消息年龄、发布 QPS、确认延迟、nack 数、return 数、unroutable 数、redeliver 数、消费者数、死信数、CPU、内存、磁盘、流控次数 |
| Outbox | pending/leased/published 数、最老 pending 年龄、发布成功数、发布失败数、失败码、租约丢失数、cleanup 耗时、cleanup 删除行数 |
| Worker | 消费 QPS、处理 P95、通知可见延迟、ack/nack/requeue 数、重试数、死信数、prefetch 使用率、CPU、内存 |
| Indexer | 消费 QPS、ES 写入 P95、搜索可见延迟、ack/nack/requeue 数、重试数、死信数、prefetch 使用率、CPU、内存 |
| Elasticsearch | 查询 QPS、写入 QPS、P50/P95/P99、`timed_out` 数、`_shards.failed` 数、线程池 queue/rejected、CPU、heap、GC 时间、磁盘使用率、segment 数、refresh/merge 耗时、PIT 失败数 |
| 主机 / 容器 | CPU、内存、CFS throttle、OOM、Swap、磁盘 IOPS、磁盘延迟、磁盘使用率、网络吞吐、网络重传、网络丢包、文件描述符 |
| 压测端 | 计划到达率、实际到达率、完成请求数、错误数、`dropped_iterations`、连接数、CPU、网络 |
| 一次性任务 | migrate 耗时、锁等待；search-init/search-reindex 耗时、文档/秒、bulk 失败数 |
