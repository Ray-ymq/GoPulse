# PT 测试指标清单与记录模板

日期：2026-10-22。

本表汇总测试一至测试六及相关历史专项的测量需求。每个独立组或档位复制一份填写；组件、实例、连接池和业务路由分别记录。清单不表示现有工具已支持全部采集，专项指标按本轮方案选用。

“本轮记录”填写实测值及证据路径。未测或不适用时写明原因，采集缺失不能填成 0。预热、正式测量和恢复分别统计；RPS 使用实际窗口时长，累计计数使用窗口增量。延迟使用 ms，累计等待使用 s，内存使用 MiB/GiB，比例使用 %。

## 1. 测试条件

先记录比较条件，避免把版本、数据或配置变化当作性能变化。

| 项目 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 测试标识 | 测试编号、轮次、组名、档位、运行目录 | 待填写 |
| 版本与部署 | 代码 commit、未提交改动、运行程序及工具版本、服务角色和副本数、是否同机压测 | 待填写 |
| 生效配置 | CPU/内存配额、连接池、并发预算、限流、超时、Redis 开关、TTL | 待填写 |
| 数据起点 | 数据快照、数据规模、data_epoch、缓存状态、历史 Outbox、初始积压、账号及语料数量 | 待填写 |
| 工作负载 | 业务比例、访问分布、目标 RPS、VU 数、客户端超时 | 待填写 |
| 测量窗口 | 各阶段起止时间、时区、实际时长、提前结束原因 | 待填写 |
| 本轮判据 | 错误率、P95/P99、实际负载、丢弃迭代、资源保护、采集完整性及停压要求 | 待填写 |

## 2. 业务表现与负载有效性

同时记录负载、成功结果和短时异常。总体与成功请求的延迟分开，各路由分别统计。

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 请求速率 | 目标 RPS、实际开始 RPS、实际完成 RPS、有效成功 RPS | 待填写 |
| 请求计数 | 开始、完成、成功、失败、最终未完成请求数；成功率、失败率 | 待填写 |
| 迭代丢弃 | dropped iterations 数量及比例 | 待填写 |
| 响应延迟 | 全部请求与成功请求的 P50、P95、P99；各路由对应分位数 | 待填写 |
| 错误分类 | 429、500、503、其他非预期响应及 error_code；超时、传输错误、停压取消 | 待填写 |
| 首次失败 | 时间、阶段、档位、路由、状态码、原因、已运行时长 | 待填写 |
| 持续稳定性 | 每秒/每分钟吞吐、错误率、延迟；异常窗口及持续时间、积压增长趋势 | 待填写 |
| 负载真实性 | 实际业务比例、有效读写数、语料剩余量；删除 204 与已不存在的 404 分开计数 | 待填写 |

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |

| 内存 | 实际上限、当前用量、窗口均值和峰值、OOM/OOM kill；RSS 与 cgroup 内存分开 | 待填写 |
| 进程与容器 | 进程数、退出状态、崩溃、非计划重启、容器身份变化 | 待填写 |
| 主机资源 | CPU、系统负载、可用内存、swap、OOM、磁盘剩余空间 | 待填写 |
| 磁盘与网络 | 磁盘读写次数、字节数、耗时、繁忙程度；网络收发量、错误、丢包 | 待填写 |
| 压测器 | VU 数、CPU、内存、网络、是否先达到发压能力上限 | 待填写 |
| HTTP 并发 | 当前及峰值 in-flight、并发上限、全局准入拒绝数 | 待填写 |

| 应用数据库操作 | 各操作次数、耗时、失败数及原因 | 待填写 |
| 应用连接池 | 各池上限、已打开连接数、使用中连接数；等待次数、累计及平均等待时间 | 待填写 |
| 多实例分配 | 各 backend 请求分布、各 worker/indexer 实际处理量 | 待填写 |

## 4. MySQL 诊断

用连接、SQL、事务、锁和 I/O 解释业务退化。统计指标按正式窗口计算，失败现场保留时间和关联对象。

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 可用性 | 独立新连接执行 SELECT 1 的成功率、耗时、失败阶段/原因、连续失败时长；Uptime、启动时间、重启次数 | 待填写 |
| 连接与线程 | 当前/峰值连接数、连接上限、活跃线程、新建连接速率、连接失败、异常断开、线程创建数 | 待填写 |
| 基础 SQL | 查询次数及速率、慢查询数、SELECT/INSERT/UPDATE/DELETE 次数 | 待填写 |
| SQL 摘要 | 按 digest 记录执行次数、累计/平均耗时、错误、扫描/返回行数、临时磁盘表、未使用索引次数 | 待填写 |
| 参数化执行 | Prepare、Execute、Close stmt 等事件的次数、累计耗时、错误数 | 待填写 |
| 提交与回滚 | COMMIT 次数、累计/平均耗时；ROLLBACK 次数；完整事务吞吐如另有测量，注明来源 | 待填写 |
| 事务状态 | RUNNING/LOCK WAIT/COMMITTING/ROLLING BACK 事务数；最老年龄、最长锁等待、锁定/修改行数 | 待填写 |
| 全库行锁 | 等待次数、累计等待时间、当前等待数、死锁数 | 待填写 |
| 热点行锁 | 按库/表/索引记录等待事务数、阻塞事务数、最长等待 | 待填写 |
| 阻塞现场 | 等待方/阻塞方事务及线程 ID、开始时间、年龄、SQL、锁对象、模式、数据和阻塞关系 | 待填写 |
| 元数据锁 | 对象、锁类型、PENDING/GRANTED 状态、持有者、等待者 | 待填写 |
| 错误与慢语句 | 锁等待超时、死锁、查询中断及其他错误码；慢语句/错误历史及时间 | 待填写 |
| Buffer Pool | 容量、数据量、脏页、总页/空闲页、逻辑读/物理读、命中率、等待空闲页次数 | 待填写 |
| 临时表与 Undo | 内存/磁盘临时表数、Undo 历史长度、Undo 槽位使用量 | 待填写 |
| Redo | 容量、当前/checkpoint LSN、checkpoint age、日志等待、待写入/待同步数量 | 待填写 |
| 文件 I/O | redo/binlog/数据文件的读写次数、字节数、累计耗时；misc 次数/耗时；观察到的 sync 事件及耗时 | 待填写 |
| 内部等待 | mutex、condition、rwlock、sxlock 等事件的次数及累计耗时 | 待填写 |
| 表与索引访问 | 按表/索引及 fetch/insert/update/delete 记录次数和累计耗时 | 待填写 |

## 5. 异步链路与缓存

异步吞吐按实际事件统计。缓存同时记录命中和回源，Redis 开关或 TTL 对照按专项方案执行。

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 事件吞吐 | 实际提交、发布确认成功/失败、Outbox 标记 published、消费、最终应用完成的数量及速率 | 待填写 |
| Outbox 操作 | claim/cleanup 次数、成功/失败、耗时分布；清理候选数、删除数 | 待填写 |
| Outbox 积压 | pending/leased 等状态数量、最老积压年龄、增长/排空速率 | 待填写 |
| 消息队列 | 各队列 ready/unacked；重试、重复处理、parked 数量 | 待填写 |
| 异步预算 | 全部 epoch 的 open_requirements、parked_messages；保留组数/字节数、扣账异常 | 待填写 |
| 历史规模 | 已发布 Outbox、commands/requirements 等记录规模、数据/索引占用、清理效果 | 待填写 |
| 应用缓存 | 命中、未命中、命中率；回源次数/耗时；缓存写入成功/失败 | 待填写 |
| 缓存重建 | 在途重建数、当前/已注册 waiter、重建拒绝数 | 待填写 |
| Redis 专项 | CPU、内存及上限占比、连接数、命中/未命中、淘汰；开关/TTL 对照中的回源、详情失败及数据库负载变化 | 待填写 |

## 6. 数据正确性与恢复

写入核对按资源 ID 或请求路径检查最终事实，跨窗口请求单列。停压后的业务探测遵循本轮方案，PT6 只做只读恢复观测。

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 写入核对 | 新建/更新/删除的实际结果；资源 ID、作者、内容、revision；点赞/书签/关注最终状态 | 待填写 |
| 一致性异常 | 缺失行、内容不匹配、无对应请求的新建行、孤儿行、HTTP 结果与数据库事实不一致数量 | 待填写 |
| 搜索应用 | 创建/修改/删除最终结果；applied、重复、重试、parked 数量；旧版本覆盖异常 | 待填写 |
| 窗口边界请求 | 窗口前开始但窗口内完成、窗口内开始但窗口后完成的请求数及核对结果 | 待填写 |
| 自然恢复 | 观察时长、实际恢复耗时、资源是否回到基线、残留积压/最老年龄、队列及全部 epoch 预算是否归零 | 待填写 |
| 业务恢复探测 | 本轮允许的探测、成功率、耗时；仅完成只读观测时注明读写恢复未验证 | 待填写 |
| 人工干预 | 是否需要干预、操作、时间、干预后恢复耗时 | 待填写 |

## 7. 采集质量与按需剖析

同时记录采集是否有效及其开销，避免把缺失数据解释为没有异常。pprof 按需启用。

| 指标项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 采集状态 | 各采集器启用/成功状态、失败次数、耗时、心跳、退出状态、实际采样数 | 待填写 |
| 证据完整性 | 缺样、采样间隔、窗口边界覆盖、截断、计数重置、序列缺失、digest 丢失 | 待填写 |
| 采集配置 | Performance Schema、consumers、instruments 的启用及计时状态 | 待填写 |
| 历史覆盖 | 事件读取范围、时间域、缓冲区覆盖限制、读取游标是否成功推进 | 待填写 |
| 采集开销 | 采集进程 CPU/内存、单次查询耗时、对业务的影响及证据 | 待填写 |
| 按需 pprof | CPU、heap、goroutine、block、mutex；采样配置、起止时间、文件路径 | 待填写 |

## 8. 本轮结论

分别填写业务结果、诊断完整性与故障边界。没有测到的边界写“未测出”，未发生的故障写“未观察到”。

| 结论项 | 填写内容 | 本轮记录 |
| --- | --- | --- |
| 通过与停压 | 最后通过档、首次异常/停压档、负载是否通过、诊断是否完整、停压原因 | 待填写 |
| 业务容量 | 达标负载区间、测量时长、持续测试结果及适用条件 | 待填写 |
| 吞吐与过载 | 最大有效成功吞吐、最高实际负载、吞吐平台、拒绝/延迟/积压变化 | 待填写 |
| 故障边界 | 业务失稳、数据库持续不可用、进程崩溃分别给出结论和证据 | 待填写 |
| 恢复与限制 | 自然恢复结果、人工干预、压测器/采集器是否先受限、未验证事项 | 待填写 |

填写时保留以下口径：SQL 累计耗时不等于 CPU 时间，文件 misc 不等于 fsync，锁快照条数不等于锁事件次数，发布确认不等于落库成功。历史常用的 1% 错误率与 PT6 的首败停压分别按对应方案执行。
