# 下一轮压测配置

配置文件：[perflab/k6/next.json](../../perflab/k6/next.json)。按实际环境修改 target 地址及 corpus、credentials 路径。

| 项目 | 配置 |
| --- | --- |
| VU / 请求超时 | 1024 / 5 秒 |
| 混合比例 | 沿用现有 22 条路由及 45/10/10/15/15/5 比例 |
| boundary | 从 10 RPS 开始，每档翻倍；预热 30 秒、测量 120 秒、恢复 120 秒 |
| refine | 测量 300 秒、恢复 120 秒；区间宽度 10%，最多 8 次二分 |
| soak | 稳定档的 80%；测量 1800 秒、恢复 120 秒 |
| SLO | 错误率 1%、P95 1 秒、P99 2 秒 |
| 早停参数 | 错误率 20% / 30 秒；健康检查失败 30 秒 |
| backlog | http://127.0.0.1:18081/backlog，要求观测恢复 |

现有 runner 必填 max_rps，配置取其支持的最大值 1000000，作为扫描保护值；逐档测到失稳即停，不把 1000 或 1600 RPS 当容量上限。

```sh
make load MODE=boundary CONFIG=perflab/k6/next.json DRY_RUN=1
make load MODE=boundary CONFIG=perflab/k6/next.json
make load MODE=refine CONFIG=perflab/k6/next.json PREVIOUS_REPORT=".run/load/next/reports/boundary-<timestamp>.json"
make load MODE=soak CONFIG=perflab/k6/next.json PREVIOUS_REPORT=".run/load/next/reports/refine-<timestamp>.json"
```

报告输出到 `.run/load/next/reports`。本次只提供配置；当前脚本的 1% 提前中止、实际测量时长和删除语料轮换问题仍需单独修复，JSON 参数不能解决。
